# Brief Description

**CityOS (Civitas AI)** is an AI-powered Autonomous Multi-Agent Decision Intelligence Platform built to help Hanoi's city operators reason about complex, fast-moving urban events and act on them in real time. A goal-driven Planner decomposes an incoming situation into a dependency-aware task graph, dispatching specialized agents — Traffic, Environment, Emergency, Citizen, and Knowledge — that run in parallel and reflect on their own confidence before a Decision stage synthesizes an explainable, human-approved recommendation. Every agent cites structured evidence (source, type, confidence, timestamp) rather than bare prose, and a rule-based Critic reviews that evidence for sufficiency and unsupported claims — a weak or contradicted decision automatically routes to human approval rather than shipping silently. Underpinning this is a unified knowledge layer that ingests OpenStreetMap, Wikipedia, Wikidata, GeoJSON district boundaries, and government PDFs into a Neo4j knowledge graph — queried live by the Knowledge Agent, not just written to — and a Qdrant vector store, retrieved through a full embed → search → rerank RAG pipeline. CityOS runs its reasoning on NVIDIA Nemotron models via OpenRouter — dedicated models for planning, embedding, reranking, and content-safety guardrails — sitting behind a single AI Gateway so the backing model can change without touching a single agent, with automatic fallback to Google Gemini for resilience. The result is a Decision Workspace where operators watch agents think in a live execution trace, review confidence/risk/evidence tiles and Critic warnings on every decision, track a session's real baseline-vs-observed CityScore outcome after approval, and approve or reject AI-generated decisions for real emergencies like flash floods and hazardous air quality — in English or Vietnamese.
